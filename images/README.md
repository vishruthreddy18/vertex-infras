# Project Images — Naming Convention

Each folder below corresponds to one project page. Drop files into the matching folder using these filenames (any of .jpg / .jpeg / .png / .webp is fine — just keep the base name exact):

- `thumb` — the card image shown on the Projects page (and homepage showcase, for Vertex Vista / Wellington / Vihanta)
- `hero` — the large banner image at the top of the project's detail page
- `gallery-1`, `gallery-2`, `gallery-3`, `gallery-4` — the 4 images in the detail page's Gallery section
- `floorplan-1` — floor plan image (only needed for residential projects that show floor plans: Vertex Vista, Vertex Wellington, Vertex Vihanta)

You don't need all of them — drop in whatever you have (even just `thumb` and `hero` is a big upgrade over the current stock photos) and let us know which project is done.
